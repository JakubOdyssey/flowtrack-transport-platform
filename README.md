# FlowTrack Transport Platform

FlowTrack is a transport operations and fleet management platform designed for transport coordinators and logistics teams.

It combines live vehicle tracking, load planning, maintenance monitoring, operational analytics and fleet tools in one system.

## Live Demo

https://free-nextjs-admin-dashboard-main-mu.vercel.app/

## Features

- Live fleet map with vehicle locations and route visibility
- Fleet and transport overview
- Trailer load planner with drag-and-drop pallet placement
- Trailer floor-space and occupancy calculations
- Cargo weight estimation
- Maintenance alerts and vehicle status monitoring
- Fuel tracking
- Operational analytics
- Load management
- Document management
- Responsive dashboard interface

## Trailer Planner

The trailer planning module allows coordinators to visually arrange pallets using drag and drop.

It provides:

- Euro pallet support
- UK pallet support
- Industrial pallet support
- Half and quarter pallet support
- Floor-space calculations
- Occupancy percentage
- Pallet count
- Estimated cargo weight

## Technology

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel

## Background

The project uses TailAdmin as an original UI foundation and has been significantly extended and adapted into the FlowTrack transport operations platform.

Custom development includes transport-specific functionality, fleet workflows, live mapping, load planning and operational tooling.
